# Store Data Analysis Using Excel

### 📊 Project Overview
This is an end-to-end E-commerce Store Sales Analysis project done in Microsoft Excel. The goal was to analyze 30,000+ orders to understand sales trends, customer behavior, and channel performance.

### 📁 Dataset
- Total Rows: 31,047 Orders
- Key Columns: Order ID, Gender, Age Group, Channel, Category, Amount, Location

### 📈 Dashboards Created
- Annual Sales Report
- Channel Performance (Amazon 35%, Myntra 23%, Flipkart 21%)
- Customer Demographics (Age & Gender)
- Sales vs Orders Trend

### 🛠️ Excel Skills Used
- Pivot Tables & Pivot Charts, VLOOKUP, SUMIFS, COUNTIFS, Data Cleaning, Charts

### 🎯 Key Insights
- Women customers ~70%
- Highest sales in Feb & March
- Amazon is top channel
